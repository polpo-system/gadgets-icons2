# gadgets-icons2

`Icons2.Lib` of ETH Native Oberon for the gadgets of [polpo](https://github.com/polpo-system/polpo):
the library of icons that documents show for themselves (`Icons2.Solitaire`, `Icons2.Bombe` and
others). The games Solitaire, Spider, Freecell and Mine Sweeper use it.

```
portia.Install gadgets-icons2
```

## What is here

    share/Icons2.Lib       the icon library, unchanged from Native Oberon 2.3.6
    tools/Icons2.Tool      what it is for
    test/Icons2Test.Mod

## Tests

    Icons2Test.Run      2 checks: icons found by name; it needs the desktop's display
